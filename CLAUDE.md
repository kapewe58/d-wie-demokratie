# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project overview

Static website for the initiative *D wie Demokratie*, built with Astro. Published at https://d-wie-demokratie.de. All content is in German. The whole site addresses readers with „du“ (lowercase), not „Sie“ (since 2026-11-12); e-mails to companies and officials stay formal. The site's purpose: present the "D wie Demokratie" sticker and the initiative behind it, and get people to share it.

## Commands

```sh
npm run dev      # dev server at localhost:4321
npm run build    # build to ./dist/
npm run preview  # preview the built site locally
```

No test suite exists.

## Deployment

Push to `main` triggers GitHub Actions (`.github/workflows/deploy.yml`), which builds and rsyncs `dist/` to `/var/www/d-wie-demokratie/` on the same Hetzner server as 5-finger.com (nginx config: `/etc/nginx/sites-available/d-wie-demokratie`, HTTPS via certbot).

## Architecture

- `src/layouts/Layout.astro`: shared `<head>` (meta, Open Graph, Umami script), sticky header with black-red-gold stripe and tab navigation, footer links. Global CSS variables live here. Also holds the tab order (`reiter`) used for swiping between tabs on mobile and for the slide animation (native cross-document View Transitions, only on touch devices); a new tab must be added there as well as in the nav. The ☰ menu at the right of the header lists all pages (array `menue`, plus Impressum/Datenschutz in `menueKlein`); a new page without its own tab only goes there, and such a page gets its own red-underlined tab for the current page (`aktuell`): on phones it replaces „Motive“ (short name `handy`, e.g. „Einreichen“, „Geschichte“), from 700 px it sits after „Motive“ (name `kurz`, e.g. „Flaggengeschichte“). Tabs since 2026-11-18: logo (start), Fragen, Verbündete, Motive; „Mitmachen“ and „Unterstützen“ are only in the ☰ menu. These tabs are not part of `reiter`/swiping. Pages not in the menu (Statistik) mark the ☰ with the red bar instead. Header widths are tuned so everything fits from 320 px; re-measure after changing tab names.
- `src/pages/index.astro`: landing page: photo slider at the top (crossfade every few seconds, dots below stop it; `bilder` array at the top, files in `src/assets/slider/`, new ones 1800 × 1200 px JPEG named `motiv-<nr>-<was>.jpg`; each photo links to `/motive/#motiv-<nr>` of the motif it shows; the photos are AI-generated, hence the visible "KI-generiert" note (Art. 50 AI Act, must stay visible, not behind a click) for entries with `foto: true`), then visible h1 „Wir zeigen Flagge“, the values with links to Art. 1–5 GG, a box styled as the flag (black-red-gold stripes, with the 1990 Reichstag photo as a grey watermark; its credit sits below the box) that rotates quotes (array `zitate` at the top: Klopp, Steinmeier …; each with an `id` such as `zitat-aigner`, so `/#zitat-aigner` shows that quote and stops the rotation; each with a button to the video or speech, only linked, not embedded; Klopp's video also linked in FAQ `#farben`), then a preview of all motifs (thumbnails of the first version, each linking to `/motive/#motiv-<nr>`; later only the newest). Old anchors `/#motiv-<nr>`, `/#motive`, `/#herunterladen` and `/#shop` are forwarded to `/motive/` by an inline script.
- `src/pages/motive.astro`: tab „Motive“ (since 2026-11-18): intro (we want many motifs, from children, artists, designers …; link to „Motiv einreichen“), then two accordion questions (`<details>`, `#herunterladen` and `#shop` open them; download terms: print and share freely, don't alter; shop: Spreadshop by Spreadshirt (Leipzig) https://d-wie-demokratie.myspreadshop.de/, set up as Non-Profit-Shop (margin 0, customer pays Spreadshirt's base price), only organic-cotton textiles (mostly Stanley/Stella); Spreadshirt is the seller, 30-day return/exchange; linked from the question (button) and per motif or per version (`shop` in `liste` or in a `varianten` entry, `/all?mainDesignId=<id>`; switch `shopAktiv`), not embedded, so the site stays free of third-party cookies; biotshirt (YTWOO, Düsseldorf) was linked 2026-11-12 to 2026-11-18 and dropped because it accepts no returns (texts in commit 7918eb7); wording rule: never call products „GOTS-zertifiziert“, only say what the product pages state, e.g. „aus Bio-Baumwolle“) then the numbered motifs one under another (list `liste` in `src/data/motive.ts`, shared with the landing-page preview, each linkable via `/motive/#motiv-<nr>`), each with links to PNG, PDF and its shop search. Per motif: PNG `src/assets/motive/d-wie-demokratie-motiv-<nr>.png` (4000 px, transparent; thumbnail and download) and PDF `public/download/d-wie-demokratie-motiv-<nr>.pdf` (CMYK); a motif only shows once its PNG exists, a missing PDF or shop link just drops that link. Klaus keeps all motif files (PDF and PNG, same name) in `motive/` (gitignored working folder, a mirror of the published files) and exports there from Affinity; when he says so, Claude compares it with `src/assets/motive/` and `public/download/`, checks only new or changed files (size, transparency, sRGB, PDF/X-4, FOGRA39, exact CMYK values, no layers, no images) and copies them over. Numbers are only given to finished motifs (print PNG exists), in order of completion; drafts never get a number. A draft has `bald: true` and `id` (anchor `/motive/#<id>`, preview file `src/assets/motive/bald/<id>.png`, Klaus's AI draft with the white outside made transparent), shows without number below the finished motifs with a gold „Kommt bald“ badge instead of download/shop links, and is left out of the landing-page preview (since 2026-11-21: hasen, hut, entchen, amsel „Oh Ei, oh Ei!“). When a draft is finished: delete `bald`/`id`, give it the next free `nr`, put the PNG in place. Motiv 3 „Vitamin D“, 4 „Demokratie braucht Schutz“ 5 „Demokratie braucht Stacheln“ 6 „Demokratie braucht Schärfe“ 7 „Dackel lieben Demokratie“ and 8 „Farbe bekennen!“ (2026-11-21) are PNG only, with embedded metadata (title, creator D wie Demokratie, contact info@d-wie-demokratie.de, usage note „frei drucken und teilen, nicht verändern“ in the copyright field; no © claim since purely AI-generated images are generally not protected in Germany) (ChatGPT image, upscaled to 4000 px in Photoshop with „Details erhalten 2.0“, white outside made transparent, reduced to 256 colours to stay under Spreadshirt's 10 MB limit). A motif can have several versions (`varianten` in `liste`, each with an `endung`; `versteckt: true` hides a version while its files stay, used since 2026-11-18 for both `-farbig` versions such as `-qr-weiss` or `-dunkel`, a button name and a short text): files `d-wie-demokratie-motiv-<nr><endung>.png` (in `src/assets/motive/`) and `.pdf` (in `public/download/`), same name, only the extension differs; buttons switch between them (without JS all are listed), each version is previewed on the fabric it is meant for: light heather grey by default, `-farbig` („Für mittlere Untergründe“) mid blue, `-dunkel` („Für dunkle Untergründe“, with white outline) anthracite (map `stoff`), or an explicit `stoff` per version (Motiv 1 „Für alle Untergründe“, white oval: mid blue-grey). PDF links carry a content hash (`?v=`) so a replaced PDF is never served from browser cache. `public/download/d-wie-demokratie-oval.png/.pdf` are kept for old links.
- `src/pages/haeufige-fragen.astro`: FAQ page, including who started the initiative; the biography with portrait (`src/assets/klaus-p-wolf.jpg`) is collapsed until the name is clicked (open without JavaScript); `/haeufige-fragen/#wer` (and `#lebenslauf`) open the question and the biography.

The design requirements moved to their own page (see `motiv-einreichen.astro`); an inline script forwards `/mitmachen/#vorgaben` there.

## Statistics

Umami, self-hosted at https://stats.5-finger.com (same server as 5-finger.com; setup documented in the 5-finger repo under `deploy/umami/`). The script in `Layout.astro` only counts on `d-wie-demokratie.de` (`data-domains`), not on localhost. Opt-out sets `localStorage['umami.disabled'] = '1'` via `/statistik/`. Click events use `data-umami-event` attributes (share buttons in the "Bitte weitersagen" box, support e-mail links, job application e-mail links `email-job`, design submission link `email-design`, sign-up as Verbündete `email-verbuendete`, downloads `download-png`/`download-pdf`, shop link `shop-oeffnen`, newsletter sign-up `neuigkeiten-anmelden`); opening the biography on the FAQ page is counted via `umami.track('lebenslauf-aufklappen')`, opening „Werte und Ziele“ on `/verbuendete/` via `umami.track('werte-ziele-aufklappen')`. If what is collected changes, update section 3 of `datenschutz.astro`.

## Design conventions

Colors (CSS variables in `Layout.astro`): `--schwarz: #000000`, `--rot: #dd0000`, `--gold: #ffce00`. Font: system Helvetica/Arial stack, matching the sticker. Content max-width: 680 px.
